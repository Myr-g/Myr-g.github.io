Mousebound

Apr 2025 – Mar 2026

A cozy 2D platformer where you play as a small mouse trying to free your forest from predators.

itch.io
[ read more ]

Mousebound is a short, polished platformer focused on atmosphere, and movement-based interactions. The game features hand‑crafted levels, soft lighting, and a cozy visual style. The goal was to create a small but complete experience with tight controls, smooth animations, and a warm tone.

Background art, sound effects, and music were sourced from royalty‑free libraries, allowing development focus on gameplay mechanics, level design, and overall polish. This project served as a study in scope control, iteration, and delivering a finished game within a reasonable time frame (~1 year).

My Contributions

As one of the two developers that made Mousebound, I worked on a lot of core gameplay features and level design. I refactored all of the player object code to use state machines for readability & maintainability, designed two of the game's four bosses, and implemented a variety of other objects in the game to ensure consistent behavior during player interaction.

Outside of gameplay mechanics, I also developed most of the UI elements and scripted the menu interactions, alongside setting up the audio system that lets players change music, sound effects, and master volume individually through sliders.

GameMaker Studio 2 · GML

Roko's Basilisk (Capstone)

Oct 2024 – May 2025

A first‑person shooter with light roguelike elements, featuring procedural level generation driven by constraint satisfaction and Unreal Engine’s PCG tools.

GitHub
[ read more ]

Roko’s Basilisk is a capstone project built in Unreal Engine 5. The game combines FPS combat with minor roguelike elements, generating new levels after each run based on player performance. A constraint‑satisfaction system evaluates how the player handled the previous level and uses that data to influence the next layout, enemy composition, and difficulty pacing.

The project also includes basic behavior‑tree AI enemies with adjustable difficulty scaling. These AI agents react to player actions, navigate procedurally generated spaces, and adapt as the run progresses.

My Contributions

I implemented a large portion of the intial constraint‑satisfaction logic used to analyze player performance and feed parameters into Unreal’s PCG system. I also created some of the custom Blueprints used throughout the project and handled the integration between C++ gameplay code, Blueprint systems, and PCG graphs.

Tech

Unreal Engine 5 · C++ · Blueprints · PCG Tools · Behavior Trees
